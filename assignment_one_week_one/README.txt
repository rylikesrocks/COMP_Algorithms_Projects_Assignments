This is a project for COMP 2247 at Rochester Community and Technical College, made by Rylan Braithwaite (rylikesrocks).

It's intended use is to take a set number of students from the user, then collect scores from  each of the students from the user,
and finally find the highest score and compare that to other scores to determine a letter grade.

This is a very simple program!
It does not implement any sort of error or edge case handling, and I do not intend to add any anytime soon.
