Objective: Design a class with multiple constructors and private fields
 — the fundamental class-design skill this chapter introduces before
  you start building classes that "have" other objects.

Create a MyTime class with private int fields hour, minute, second.
Provide three constructors: a no-arg constructor that sets the time to 
the current moment (hint: System.currentTimeMillis()), a constructor 
that takes a total elapsed number of milliseconds and converts it into 
hour/minute/second, and a constructor that takes hour/minute/second directly.
Provide getters for hour, minute, and second.
In main(), construct one MyTime object using each constructor and print all 
three.
